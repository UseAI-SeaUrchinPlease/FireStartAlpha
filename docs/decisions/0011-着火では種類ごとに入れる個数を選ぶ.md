# 0011 着火では種類ごとに入れる個数を選ぶ

- 日付: 2026-11-27
- 状態: 確定
- 決めた人・場: parsley001（Claude Code との相談）
- 出典: #37

## 決めたこと

持っている素材の一覧から、種類ごとに入れる個数を選び（左右キーで増減）、「火をつける」で決定する。

（P2 の実装で、← → で素材を選び ↑ ↓ で個数を変える今の操作に合わせた。火起こし18 の要望も ↑ ↓ で個数を選ぶ前提: [0049](0049-P2の個数選択は長押しで連続して増減する.md)）

## 理由

今は役割ごとの3つの枠に、持っている素材の先頭のものが自動で入るだけで、どれを入れるか選べない。燃料も着火具も3種類になると、選べないと成り立たない。
