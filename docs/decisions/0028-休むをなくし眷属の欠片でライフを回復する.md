# 0028 休むをなくし眷属の欠片でライフを回復する

- 日付: 2026-11-28
- 状態: 確定
- 決めた人・場: parsley001（Claude Code との相談）
- 出典: [火起こし22（11/20）](https://hackmd.io/cZF2RQchSqGZqzW4FF_QVQ)「魔物の素材でライフも回復でき」、[火起こし18（10/09）](https://hackmd.io/hUJlLlR-TOCCNumgL96T7A)「休むが何回も選べてしまう」

## 決めたこと

自強化の「休む」をなくし、「ライフ回復」で眷属の欠片を1個使って体力を回復する（量は [0038](0038-体力は100の単位にする.md)）。欠片がある限り何回でも使える。

## 理由

火起こし22 が最新で、設定資料とも同じ文面。火起こし18 で「休む」を1回にしたかったのは費用がほぼなかったからで、欠片を払うなら回数の制限は要らない。
