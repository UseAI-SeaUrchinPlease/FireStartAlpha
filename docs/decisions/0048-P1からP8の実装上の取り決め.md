# 0048 P1からP8の実装上の取り決め

- 日付: 2026-11-28
- 状態: 確定
- 決めた人・場: parsley001（Claude Code との相談）
- 出典: plan-reviewer の指摘への対応

## 決めたこと

着火画面を開くキーは今使っていない interact（E）。昼のワールドとプレイヤーは着火画面の下で止めて残し、夜へ渡す。追加の素材3種（鱗片・火口・古木）は、名前・分類・熱量・四角の見た目だけ P3 で足し、効果は P6。素材の .tres のファイル名と id は残して表示名だけ変える。陽だまりの枯れ枝は ItemData の TINDER にし、画面では「燃料」と表示する。眷属の欠片は着火画面の一覧に出さない。攻撃速度と移動速度は P5 で GameState に足す。アンロックの説明文の素材名は P2 で新しい名前に直す。P5 で UpgradeData に、使う素材・個数・レベルごとの眷属の欠片の個数を持たせる。テストは、各 PR で変えた仕様に当たる既存テストを直し、新しい仕組みは成否の分岐を1つずつテストする。

## 理由

どれも後から変えられる小さな判断で、コードの今の形に合わせた。
