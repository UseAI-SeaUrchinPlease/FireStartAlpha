# 0014 P2 で今の3素材を新しい名前にする

- 日付: 2026-11-27
- 状態: 確定
- 決めた人・場: parsley001（Claude Code との相談）
- 出典: #37, #41

## 決めたこと

| 今 | 新しい名前 | 分類 |
|---|---|---|
| 薪 | 灰被りの薪 | 燃料 |
| 枯れ草 | 陽だまりの枯れ枝 | 燃料 |
| 火打石 | 星屑の火打石 | 着火具 |

残りの3つ（琥珀脂の古木、火蜥蜴の鱗片、灰神楽の火口）は、効果と一緒に P6（#41）で追加する。（あとで、データだけ P3 で先に足すことにした: [0048](0048-P1からP8の実装上の取り決め.md)）

## 理由

今の枯れ草は火口の役割だが、2分類（0009）に合わせて燃料に入れる。
