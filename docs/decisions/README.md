# 意思決定の記録

決めたことの履歴。今の仕様は [DEVELOPMENT.md](../../DEVELOPMENT.md) に書き、ここには「いつ・誰が・なぜそう決めたか」を残す。仮決めと未決は [docs/todo.md](../todo.md) にある。

## 書き方

1つの決定につき1ファイル。ファイル名は `NNNN-決めたことの要約.md`（NNNN は4桁の連番）。

```markdown
# NNNN 決めたことの要約

- 日付: YYYY-MM-DD
- 状態: 確定 / 仮 / 置き換え: NNNN
- 決めた人・場: 会議名、Issue や PR のコメント、相談した相手など
- 出典: Issue・PR の番号、議事録、設定資料など

## 決めたこと

## 理由
```

決定が変わったら、古いファイルは消さずに状態を「置き換え: NNNN」にし、新しいファイルを足す。
