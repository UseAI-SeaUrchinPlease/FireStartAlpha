# 0026 昼は魔物を出さない

- 日付: 2026-11-27
- 状態: 確定
- 決めた人・場: parsley001（Claude Code との相談）
- 出典: [火起こし21（11/13）](https://hackmd.io/QiytLGJUSp6FesANK2g0Vw)「太陽が上っていないと魔物が出てくるようになってしまった」、[火起こし22（11/20）](https://hackmd.io/cZF2RQchSqGZqzW4FF_QVQ)「日没後には…『虚空の眷属』が這い出る」

## 決めたこと

昼には魔物を出さない。今の昼のゾンビは消す（P1）。

## 理由

新しい設計を決めた2回の議事録が、どちらも魔物は日が出ていないときに出るとしている。古い火起こし13（8/27）の「昼もゾンビが出る」より新しい。
