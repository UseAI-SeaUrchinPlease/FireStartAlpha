# 0036 自強化画面は4つのボタンにする

- 日付: 2026-11-27
- 状態: 確定
- 決めた人・場: parsley001（Claude Code との相談）
- 出典: #40 の題、[ワンページャー](../design-memos/one-pager.png)、[手書きの画面スケッチ](../design-memos/screen-sketch.png)

## 決めたこと

自強化画面は「パラメーター強化」「装備製作」「ライフ回復」「夜を明かす」の4ボタン。「装備製作」で装備を作り（レベル1）、「パラメーター強化」で作った装備のレベルを上げる。どちらも押すと装備の一覧が開く。装備のレベルがパラメーターになる考え方（0024）は保つ。

## 理由

メモと #40 の題がボタンを分けている。0024 の「装備＝パラメーター」を保ったまま当てはめられる。
