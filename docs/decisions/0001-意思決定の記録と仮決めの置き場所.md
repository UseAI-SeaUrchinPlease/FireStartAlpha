# 0001 意思決定の記録と仮決めの置き場所

- 日付: 2026-11-27
- 状態: 確定
- 決めた人・場: parsley001（Claude Code との相談）
- 出典: 会話

## 決めたこと

- 決めたことの履歴は `docs/decisions/` に、1つの決定につき1ファイルで残す
- 仮決めと未決は `docs/todo.md` にまとめる。DEVELOPMENT.md の「7. 未決事項」もここへ移す
- DEVELOPMENT.md は今までどおり「今の仕様」として、最新の決定だけを書く
- この運用を AGENTS.md に書き、開発しながら更新する

## 理由

DEVELOPMENT.md は最新の状態に書き換えていく文書なので、いつ・なぜ変わったかが残らない。1ファイルずつに分けると、PR で決定が追加・変更されたことがレビューで見える。TODO が2か所にあると片方が古くなるため、1か所にまとめる。
