# 0035 着火画面で火をつけられる条件

- 日付: 2026-11-28
- 状態: 確定
- 決めた人・場: parsley001（Claude Code との相談）
- 出典: [ワンページャー](../design-memos/one-pager.png)「失敗でゲームオーバー」

## 決めたこと

昼に自分で開いたときは、温度が足切り温度に届いていなければ「火をつける」を押せない。日没で開いたときは、所持素材を全て入れても足りない時のみゲームオーバーにする。足りる組み合わせがあるなら、足りるまで押せない。P2（#37）で入れる。

## 理由

自分で開いたなら戻って集め直せるので、押せると失敗がただの押し間違いになる。
