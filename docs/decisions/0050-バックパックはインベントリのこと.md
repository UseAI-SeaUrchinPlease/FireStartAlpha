# 0050 「バックパックに配置」はインベントリのこと

- 日付: 2026-11-28
- 状態: 確定
- 決めた人・場: Tomamamama（PR #52 のレビュー）
- 出典: [PR #52 のレビュー](https://github.com/UseAI-SeaUrchinPlease/FireStartAlpha/pull/52)「バックパックに配置は入手したアイテムを見られる場所としてインベントリ的な要素として考えていたが、優先順位は低い」、[ワンページャー](../design-memos/one-pager.png)のコアループ

## 決めたこと

ワンページャーと火起こし22 の「バックパックに配置」は、入手した素材を見られるインベントリのこと。マス目に並べて置く仕組みは作らない。着火の操作は [0011](0011-着火では種類ごとに入れる個数を選ぶ.md) のまま。インベントリの表示は P7（#42）の HUD で扱い、優先順位は低い。

## 理由

PR #52 で確認を頼んだところ、レビューでこう返ってきた。
