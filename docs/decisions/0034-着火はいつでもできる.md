# 0034 着火はいつでもできる

- 日付: 2026-11-27
- 状態: 確定
- 決めた人・場: parsley001（Claude Code との相談）
- 出典: [火起こし21（11/13）](https://hackmd.io/QiytLGJUSp6FesANK2g0Vw)「火起こしフェーズ（いつでも可能）」、[火起こし18（10/09）](https://hackmd.io/hUJlLlR-TOCCNumgL96T7A)「拠点がないのになんで夜いきなり火をつけるフェーズに行けるのか」

## 決めたこと

昼のあいだは E で、いつでもその場で着火画面を開ける。開いているあいだは日没タイマーを止める。成功したらその場所に焚火を置き、残りの昼を飛ばして夜にする。昼に自分で開いたときは「戻る」で昼に戻れる。日没までに着火しなければ、その場で着火画面が開き、戻れない。焚火のまわりの円が結界で、魔物は結界に入れず、中ではダメージを受けない（0019 から引き継ぐ）。

## 理由

プレイヤーが野営地を選べるので、火起こし18 の疑問にも答えられる。タイマーを止めないと、素材を選んでいるうちに日没になってしまう。
