# 0040 着火具3種の効果と連鎖

- 日付: 2026-11-27
- 状態: 確定
- 決めた人・場: parsley001（Claude Code との相談）
- 出典: 設定資料（#41 のコメント）、[ワンページャー](../design-memos/one-pager.png)のコアループ「着火・連鎖」

## 決めたこと

星屑の火打石: 熱量が小さく、特別な効果なし。灰神楽の火口: 1個以上あれば入れた枯れ枝すべての熱量が2倍（重ねて効かない。火口自身にも小さい熱量がある）。火蜥蜴の鱗片: 熱量が大きく、雨の影響を緩める。「連鎖」は火口×枯れ枝のような組み合わせの効果として扱う。

## 理由

設定資料の役割（基本の着火具／種火へ育てる／悪天候でも確実に着火）に沿わせた。「連鎖」の説明はどこにもないので、作り込まずに済ませる。
