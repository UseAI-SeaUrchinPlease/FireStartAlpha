# 0032 素材図鑑は文字の一覧にする

- 日付: 2026-11-27
- 状態: 仮
- 決めた人・場: parsley001（Claude Code との相談）
- 出典: #42「オプション(素材図鑑)」、[手書きの画面スケッチ](../design-memos/screen-sketch.png)「素材図鑑などがみられる」、[火起こし21（11/13）](https://hackmd.io/QiytLGJUSp6FesANK2g0Vw)「素材表作成」、[火起こし17（10/02）](https://hackmd.io/1VZYV-DWRrehFfZ0_M14Gw)「ゲーム内の説明が乏しい」

## 決めたこと

素材6種の名前・分類・役割を1行ずつ並べた文字の一覧にし、オプションから開く。

## 理由

展示会で初めて遊ぶ人に素材の役割を伝える手段がほかにない。文字の一覧なら小さく作れる。
