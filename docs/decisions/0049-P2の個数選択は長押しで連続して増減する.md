# 0049 P2 の個数選択は長押しで連続して増減する

- 日付: 2026-11-27
- 状態: 確定
- 決めた人・場: parsley001（Claude Code との相談）
- 出典: [火起こし18（10/09）](https://hackmd.io/hUJlLlR-TOCCNumgL96T7A)「↑↓の数を選ぶ操作が、長押しで連続で数の増加、減少をしたい」、[火起こし22（11/20）](https://hackmd.io/cZF2RQchSqGZqzW4FF_QVQ)「素材をバックパックに配置し」

## 決めたこと

P2（#37）の着火画面は [0011](0011-着火では種類ごとに入れる個数を選ぶ.md) のまま種類ごとに個数を選び、キーを長押しすると連続して増減するようにする。長押しはキーボードのキーリピートを使う（コントローラーは今は考えない: [0033](0033-オプションはEscで開きゲームを止める.md)）。「バックパックに配置」の意味は鷹さんに確かめる（todo）。

## 理由

「配置」がマス目に置くことかどうか分からず、マス目なら作る量がずっと増える。長押しは火起こし18 の遊んでみようタイムで出た要望。
