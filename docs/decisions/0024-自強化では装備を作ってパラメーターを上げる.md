# 0024 自強化では装備を作ってパラメーターを上げる

- 日付: 2026-11-27
- 状態: 置き換え: 0036, 0037
- 決めた人・場: parsley001（Claude Code との相談）
- 出典: #40「素材で装備を製作し、移動・採掘・攻撃速度などを強化」、[火起こし21（11/13）](https://hackmd.io/QiytLGJUSp6FesANK2g0Vw)、[火起こし22（11/20）](https://hackmd.io/cZF2RQchSqGZqzW4FF_QVQ)

## 決めたこと

装備の製作とパラメーターの強化を1つの一覧にする。装備を作る（レベルを上げる）とパラメーターが上がる。

| 装備（仮の名前） | 上がるもの |
|---|---|
| つるはし | 採掘速度 |
| 剣 | 攻撃力 |
| 籠手 | 攻撃速度 |
| 靴 | 移動速度 |
| 鎧 | 最大HP |

## 理由

#40 の「移動・採掘・攻撃速度」に、今ある攻撃力と最大HPの強化を足した。
